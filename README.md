# Лабораторные работы по Java

Сборник из 8 лабораторных работ по дисциплине «Кроссплатформенные технологии программирования».

| №   | Тема |
|-----|------|
| [Lab1]() | Базовое знакомство с Java: компиляция и запуск программ, простые числа, палиндром |
| [Lab2]() | Объектно-ориентированное программирование: иерархия классов, принципы ООП |
| [Lab3]() | Хэш-таблицы: собственная реализация методом цепочек и использование HashMap |
| [Lab4]() | Обработка исключений: try-catch, пользовательские исключения, логирование |
| [Lab5]() | Регулярные выражения: поиск, валидация, обработка текста |
| [Lab6]() | Коллекции Java: List, Map, дженерики, работа с данными |
| [Lab7]() | Многопоточность: Thread, Runnable, ExecutorService |
| [Lab8]() | Аннотации, Stream API и многопоточная обработка данных |

В каждой папке отдельный README с описанием задания и инструкцией по запуску.
